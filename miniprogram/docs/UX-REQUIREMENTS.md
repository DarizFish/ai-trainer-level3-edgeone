# 小程序分享与实操体验需求

本轮目标：让用户能分享题目，在与网站一致的视觉体系中完成手机练习、就地核对答案，并清楚地转到电脑运行代码。本文件是本轮产品范围与验收口径；发布方式仍见 [README](../README.md)。

## 功能与验收

| 功能 | 正式需求 | 验收口径 |
| --- | --- | --- |
| 微信分享 | 已注册页面支持右上角转发给朋友；理论题、实操题分享当前题目的公开入口，功能页分享对应入口，账号与个人记录页分享首页。 | 接收者可用访客身份打开同一道题；分享参数不包含答案、收藏筛选、账号、草稿、成绩或试卷记录 ID。 |
| 视觉统一 | 沿用网站米白底、深蓝正文、朱红主操作与衬线标题；导航、选中态、卡片与弹层一致；代码区沿用网站 notebook 的 JupyterLab Light 浅灰底、白色当前行与语法配色。 | 理论、模考、实操、我的、账号和隐私页均使用统一色板；绿色仅承担一致、正确等反馈；小屏文字、按钮与代码输入不溢出。 |
| 实操首页导流 | 在首屏提供清楚的网站实操入口，说明电脑端支持运行代码、使用素材和导出文件。 | 用户无需翻到页底即可找到入口；点击后出现目的地址与使用步骤，可复制网站链接。 |
| 题内网页执行 | 代码题提供“去网页执行”，文书与分析题提供“网页实操”，打开对应题目的电脑使用指引。 | 按钮明确标示网页用途；复制链接带正确题号；不显示虚假执行结果，不把本机填写描述为已同步到网页。 |
| 就地答案对比 | 点击“对比答案”一次展开本题全部空位的参考答案，再次点击统一收起；参考条紧跟对应代码行或文书填空，同一行多空逐项展示。短答案保持一行，长答案直接换行显示全文；我的填写保留在原处。 | 绿色加文字标出一致，朱红加文字标出差异，灰色标出未填写；不显示逐项展开、关闭、说明、评分点或翻项按钮；展开时仍可填写，颜色即时更新；切换代码与报告仍保留对比，统一收起后回到原填写。 |
| 比对口径 | 比对用于文本核对，不承担 Python 执行或主观题自动评分。代码忽略安全的单行格式差异，多行保留内部缩进；文书保留内容与标点差异。 | 字符串内部空格、代码运算符、报告内容变化不得误判一致；文字不同不直接标记为错误；“已掌握／还需练习”放在填写目录的状态菜单，仍由用户自行确认。 |
| 状态连续 | 查看答案、打开网页指引、分享与返回，不覆盖草稿或参考答案，不重置题号、续练位置、账号隔离与手动自评。 | 已填写内容可恢复；未填写项保持空白；分享和查看答案不产生作答提交；键盘出现时仍保留主要阅读空间。 |

## 交付与验证边界

- 交付可在微信开发者工具预览的候选代码、自动测试结果及关键页面截图，供用户验收。
- 真机转发与接收、实际键盘和系统后台恢复需要在微信中核验；开发者工具通过不替代这些验证。
- 本轮不改变网站接口、数据库或网站发布流程；正式小程序需在验收后独立上传、审核、发布。
