## 可复现验证

从仓库根目录运行 `npm.cmd run test:miniprogram`，覆盖内容哈希、题库与试卷规则、历史答案恢复、账号隔离、离线重试、实操上下文、参考浏览和草稿恢复。根目录 `npm.cmd test` 将该检查与网站快速门禁一并运行；`npm.cmd run build` 验证网站构建边界。

**本次结果**：根目录 `npm.cmd test` 通过，包含 31 项小程序测试、57 项网站合同测试、ESLint、TypeScript 和内容审计。`SELF_HOSTED_BUILD=1` 的生产构建通过，standalone 未包含 `miniprogram/` 源码；网站存在 9 条既有导航 lint 警告，未出现错误。

迁移验收还运行 `npm.cmd run content:miniprogram:sync`，确认脚本从父目录解析题库源，输出继续匹配全部 62 个导入运行文件。通过模拟 CLI 的独立脚本检查确认：缺少 `project.private.config.json` 时，验收仍可生成临时项目配置，且不会改写源项目。该检查不启动微信界面；实际开发者工具、隔离 API 与重启诊断命令及各自边界见 [README](../README.md)。

**未重新验证**：此次 Git 初始化不包含新一轮微信真机验收、完整开发者工具遍历、生产 API 写入或代码发布。历史模拟器截图、日志和临时二维码保留在原独立目录，不进入此次 Git 基线；正式审核与发布状态以微信后台为准。
