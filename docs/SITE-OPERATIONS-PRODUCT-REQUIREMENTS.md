# 网站运营功能产品需求

本文定义网站公告、小程序引导、个人报名攻略、备用网址、ICP备案信息和自愿赞赏。它描述稳定的产品边界；会变化的考试通知、联系方式、费用和日期不在本文或页面中复制。

## 1. 目标与原则

- 从任意页面进入都能触达最新公告，同一浏览器对同一公告仅主动提示一次，不打断学习。
- 给出可执行的报名核心路径，同时把当期资格、费用、时间和材料要求留给报名渠道核验。
- 公开唯一可信的正式地址；备用网址尚未验收时如实显示未启用，不暴露服务器 IP。
- 在全站页脚逐字展示 `沪ICP备2026039336号-1`，并链接工信部备案查询站。
- 让愿意支持本站的用户容易找到赞赏入口，但不打断学习、答题、考试或实验流程。
- 在首页前半段讲清实操题的差异化价值：自动准备环境、浏览器运行、逐项核对答案和恢复模板重练。

## 2. 功能与验收口径

| 功能 | 产品方案 | 验收口径 |
| --- | --- | --- |
| 网站公告 | 全站顶部显示一条轻量公告，当前为小程序上线并引导至 `/miniprogram`；同一浏览器首次展示即记录已触达。 | 不使用弹窗、不遮挡作答；可键盘关闭；换页、返回及刷新不重复出现；新公告通过更新 `lib/site-notices.ts` 的 `id` 重新触达。浏览器禁用持久存储时尽量退回会话存储和当前页面会话去重。 |

## 3. 报名攻略内容策略

内部整理曾参考产品负责人提供的[小红书考生经验](https://www.xiaohongshu.com/explore/688cc6050000000025014df3)。这只是开发输入，不在用户页面展示；经验内容只用于提炼行动顺序，不能作为当期资格或收费事实的唯一依据。

- 保留稳定信息：目标地区/职业/等级、资格自查顺序、渠道选择原则、审核后缴费、凭证保存和资料准备。
- 不复制易变信息：电话、微信、费用、具体日期、地点、材料份数和旧批次提交方式。
- 页面提供渠道核验方向；任何支付发生前，用户必须再次确认本期开放状态、收款主体和完整流程。

## 4. 赞赏触达与体验边界

**当前状态：整条关闭。** 收款码还是占位图，留着入口只会把用户领到一个不能付款的页面——与其在页面上解释「暂不收款」，不如先不出现。开关集中在 `lib/features.ts` 的 `voluntarySupportEnabled`，页面、导航、首页提示带、sitemap 和 `/support` 路由都读它，翻成 `true` 即整体恢复，本节以下描述随之生效。

触达层级从轻到重：

1. 首页首屏结束后显示一次静态支持提示，用户可直接略过继续浏览。
2. 顶部菜单与全站页脚保留“支持本站”文字入口，供有意愿的用户主动寻找。
3. 独立支持页说明用途、非权益性质和风险边界，再展示收款码。

赞赏不得出现在做题卡、考试计时页、交卷结果、账号注册或 JupyterLite 实验操作区，也不得通过遮罩、自动展开、反复提醒或“解锁答案”等方式施压。

## 5. 发布状态与后续配置

- **已配置**：备案号及备案查询链接。
- **已关闭**：自愿赞赏（`voluntarySupportEnabled = false`）。开启前置条件——把 `public/support-code-placeholder.svg` 替换为站点负责人确认的真实收款码，用真实手机完成金额、收款主体和清晰度验收，再把开关翻成 `true`。开关关闭期间不需要在页面上解释“暂不收款”，因为入口根本不出现。
- **待配置**：取得备用域名后，完成备案、HTTPS、版本一致性、登录、模拟考试和 JupyterLite 数据边界验收，再设置 `BACKUP_SITE_ORIGIN`。
- **持续风险**：报名渠道和外部链接会变化；发现失效或口径变化时应更新核验入口，但仍不把整篇当期通知搬入本站。
